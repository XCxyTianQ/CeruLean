# 00 · 立项与约束

## 项目定位

| 项 | 内容 |
|---|---|
| 名称 | **CeruLean Cores** |
| 定位 | 半投入生产的实验项目（区别于纯试验性的 AzureBranches） |
| 目标 | 以 Paper 主线 stable 为基座，提供「区域化多线程 tick + 命令语义完整性 + 可选自研存储」的服务端发行版 |
| 与 AzureBranches 的关系 | 继任者：整体继承其命令语义（OCC）与存储资产，基座从 Folia 26.1.2 前移到 Paper 主线 |
| 发行形态 | Paperclip 风格分层容器（启动器 + bsdiff 补丁 + 依赖库），三段哈希自校验 |

## 三条硬约束

### 1. 许可证：GPLv3（不可协商）

继承链：`Bukkit / CraftBukkit → Spigot → Paper → (Folia) → AzureBranches → CeruLean`，全链 GPLv3。

必须做的事：

- 发行包附带**完整对应源码**（含本仓库全部补丁）；
- 保留上游署名与派生声明（`NOTICE` 形式），补丁文件头保留来源署名；
- 禁止闭源分发、禁止以专有许可二次授权。

### 2. 运行时：Java 25

- Paper/Minecraft 26.x 的 class 文件主版本为 **69 = Java 25**（实测：`MinecraftServer`、`FallbackRegionScheduler`）。
- Mojang 元数据要求 `java-runtime-epsilon`（majorVersion 25）。
- 本机工具链：`~/.harmonybrew/opt/openjdk@25/bin/java`（`openjdk 25.0.4.1`）。

> 因此任何"支持 Java 21"的宣称都需要单独验证，默认按 Java 25 处理。

### 3. 上游节奏：以"可复现 + 自动告警"为前提

- Mojang 最新正式版 26.3（2026-09-15），快照已到 26.4-snapshot-3；
- Paper 26.3 已出到 **build 175**（2026-10-11，首个 STABLE），26.2 线仍在维护（build 133，2026-10-09）；
- 结论：**没有自动化，就没有可持续的下游**。Phase 0 的全部工具都是为这条约束服务的。

## 范围边界（Phase 0 不做的事）

- 不接入 gradle/paperweight 构建（Phase 1）；
- 不移植任何 Folia 区域化补丁（Phase 2）；
- 不发布任何面向玩家的构建；
- 不改动 `AzureBranches` 现有仓库（资产迁移发生在 Phase 1）。
